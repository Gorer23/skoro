# Diction Lab

Мобильный PWA-тренажёр дикции со скороговорками, таймером и автоматической записью попыток.

## Как опубликовать на GitHub Pages
1. Создайте новый репозиторий, например `diction-lab`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Откройте полученную HTTPS-ссылку на телефоне.
5. На iPhone: Safari → Поделиться → На экран «Домой».

## Микрофон
GitHub Pages работает по HTTPS, поэтому браузер может запрашивать доступ к микрофону. Доступ запрашивается только после нажатия «Начать попытку».

Записи сохраняются локально в IndexedDB устройства, если включён переключатель «Хранить записи». Ничего не отправляется на сервер.

## Важно
На разных устройствах статистика, список пройденных скороговорок и записи хранятся отдельно.
